# UI Autotests: VK Video & Alchemy

Автотесты для мобильных приложений **VK Видео** (воспроизведение) и **Алхимия** (реклама/подсказки).

**Стек:** Java 22, Appium, Selenide, JUnit 5, Maven.

## ⚙️ Требования к окружению (Pre-requisites)

Перед запуском убедитесь, что:

1.  **Appium Server:** Запущен локально на порту `4723`.
2.  **Эмулятор:** Android 11.0 (API 30) с образом **Google Play**.
    * *Важно:* На эмуляторе должен быть выполнен вход в **Google Аккаунт** (для загрузки рекламы в Алхимии).
3.  **Приложения:** Установлены на эмулятор вручную (через Store или APK):
    * VK Видео (`com.vk.vkvideo`)
    * Алхимия (`com.ilyin.alchemy`)

## 🔧 Конфигурация

Параметры запуска находятся в `src/test/resources/config.properties`.
Если имя вашего эмулятора отличается от стандартного, измените параметр:

```properties
device.name=Ваше_Имя_Эмулятора
# appium.server.url=[http://127.0.0.1:4723/](http://127.0.0.1:4723/)
```
